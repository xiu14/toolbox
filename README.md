
# 🧰 Toolbox

个人脚本工具箱，新机器一行命令安装。

## 快速开始

```bash
curl -fsSL https://raw.githubusercontent.com/xiu14/toolbox/main/install.sh | bash
```

## 包含工具

| 脚本 | 描述 |
|------|------|
| proxy.sh | SSH 代理管理器 |
| deploy-st.sh | SillyTavern 部署 / 清理工具 |
| upload.sh | 输入 Cloudflare R2 信息后打包并上传 /root 备份 |
| restore.sh | 输入 Cloudflare R2 信息后下载并恢复 /root 备份 |

## 使用说明

安装后按提示完成初始化配置即可。
